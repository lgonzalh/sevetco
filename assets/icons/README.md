# Carpeta de iconos

Ver el inventario completo en [ICONOS.md](../ICONOS.md).

| Carpeta | Que contiene |
| --- | --- |
| `shared/` | Iconos que usan la app web **y** la app movil (54) |
| `web/` | Iconos exclusivos del panel web (8) |
| `mobile/` | Iconos exclusivos de la app movil (2) |
| `_descartados/` | Descargados con el nombre equivocado (4) |

Regla: un icono se guarda en una sola carpeta. Si lo usan las dos apps, va en
`shared/`; no se duplica.

Para ver todos los iconos con su nombre de un vistazo, abre
`hoja_de_contacto.png`.
